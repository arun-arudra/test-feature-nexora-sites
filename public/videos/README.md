# Portfolio videos

Replace dummy videos later:

1. Put your recordings here, e.g.:
   - cafe-desktop.mp4
   - cafe-mobile.mp4
2. Update paths in `src/config/portfolio.ts`:
   videoDesktop: "/videos/cafe-desktop.mp4"
   videoMobile: "/videos/cafe-mobile.mp4"

Tips:
- Keep files compressed (under ~8–15MB each if possible)
- Mute-friendly clips work best (site autoplays muted)
- Same clip can be used for desktop + mobile until you have both
